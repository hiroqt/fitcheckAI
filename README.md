# FitCheck AI — Landing Page & Retail Integration

High-converting, professional B2B SaaS landing page for an enterprise virtual fitting and intelligent garment drape integration engine, targeted at fashion e-commerce brand founders and store managers.

## Tech Stack
- **Framework:** Next.js 16 (App Router) & React 19
- **Styling & Design System:** Tailwind CSS v4 & Impeccable Design Governance (`DESIGN.md`, `PRODUCT.md`)
- **Components & Primitives:** Radix UI (`@radix-ui/react-*`), shadcn/ui
- **Icons & Animation:** Lucide React, Framer Motion
- **Visual FX:** Hardware-accelerated Logo Marquee, Asymmetric Bento Grid, Architectural Ambient Grids
- **Code Highlighting:** Shiki (multi-tab developer integration snippets)
- **Forms & Backend:** Next.js Server Actions with biometric parameter telemetry

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the landing page.

## Build & Quality Checks

```bash
npm run build    # Next.js static page compilation and type checking
npm run lint     # ESLint code hygiene checks
```
